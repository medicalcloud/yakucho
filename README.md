# 薬徴（東大本）原文・現代語訳

吉益東洞『薬徴』の原文を、薬ごとの小さな単位に分け、日本語訳と解説を付けて、人にも機械にも読みやすい形にしたもの。英訳はない。

本文の全単位の原文と、薬の章・自序・跋の日本語訳がそろっている。全篇の校異と校訂はまだ終えていない（「訂正と校異」を参照）。

## 構成

```
00_序跋/      自序（p001）、跋（p002）、東洞先生著述書目記（p003）
01_巻上/      石膏〜（001〜009）と目次・巻頭
02_巻中/      黄連〜（010〜032）と目次・巻頭
03_巻下/      香豉〜（033〜052）と目次・巻頭
04_刊記/
  index.md    単位の一覧
  NNN.md      原文（句読点つき）
  NNN.ja.md   日本語訳と解説
```

- 単位の番号は、東大本の順に薬に振ったもの。当帰・芎藭は1単位である。
- 東洞先生著述書目記、目次、巻頭、刊記は原文のみで、訳はない。

### ファイルの頭の情報（YAML）

| キー | 内容 |
|---|---|
| book | 書名 |
| chapter / chapter_title | 巻の番号と巻名 |
| unit | 単位の番号（ファイル名） |
| title | 単位の題 |
| folio | 東大本の画像のコマ番号 |
| punctuated | 句読点の付け方。`rule` は下記の規則で機械的に付けたもの |
| no_ja | 訳がない単位 |

訳のファイル（`.ja.md`）の頭には `unit` `lang` `source`（対応する原文のファイル）を付けている。

### 原文の句読点

原本の圏点を規則で句点と読点に分けた。圏点が也・矣・焉などの文末の字のあとにあるときや、行の終わりにあるときは句点、それ以外は読点とした。機械的に分けたので、不自然な切れ目が残っている。訳はこの切れ目にとらわれず、文意に従った。

### 訳と解説の書き方

- 訳は直訳を基本とし、節の見出し（考徴・互考・弁誤・品考）は原文と同じにした。
- 「主之」は「がこれを主る」とした。
- 解説は一般的な解釈を独自の言葉でまとめたもので、現代の注釈書からの引用はしていない。
- 引用元を確かめられなかった点、推定で訳した点は、解説にその旨を記した。
- 句読点は、原文、訳とも「、。」を使う。

## 底本と本文

### 底本

- **どのような本か**：『藥徴』三巻（東京大学理学系研究科附属植物園所蔵、請求記号 Wa:248、DOI [10.20730/300066046](https://doi.org/10.20730/300066046)）。子の猷（南涯）の跋は天明甲辰（1784）で、刊記の発行書肆は出雲寺文次郎らである。刊年の記載はない。
- **どのように入手したか**：国文学研究資料館の国書データベースで公開されている画像（全139コマ）を見て、1コマずつ書き起こした。
- **字の変換**：書き起こしは原本の字で行い、公開版では日本の新字体に直した（方針は `字体と変換の方針.md`）。「人參」の字は、原本の字形によらず「人参」に統一した。

### 訂正と校異

- 方針は、東大本のままとし、明らかな誤刻だけを改めるというものであるが、全篇の校訂は終えていない。現在の原文は、東大本の字のままである。
- 校異は、自序と石膏にだけ付いている。
- 誤刻の候補は、気づいたものを解説に記した（例：香豉の「其非其吐劑也」）。

### 比べた資料

いずれも全文の書き起こしの確認に使った。
- **中醫笈成**『藥徵』
- **殆知閣**『药征』
- **Wikisource**（中文維基文庫）『藥徵』

これらの資料には、東大本にない誤りや、跋の一部の欠落などがある。

### 確かめていないこと

- 訳は別の資料と照合しておらず、未確認の訳を含む。
- 全コマの書き起こしを読み直してはいない。読み直したのは、他の資料との差があった箇所が中心である。
- 訳の解説の一部（木芍薬の比定、「游断」「俏性」の解釈など）は推定である。
