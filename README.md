# 薬徴（東大本）原文・現代語訳

吉益東洞『薬徴』の原文を、薬ごとの小さな単位に分け、日本語訳と解説を付けて、人にも機械にも読みやすい形にしたもの。英訳はない。

本文の全単位の原文と、校異・校訂、薬の章・自序・跋の日本語訳がそろっている。

## 構成

```
00_序跋/      自序（p001）、跋（p002）、東洞先生著述書目記（p003）
01_巻上/      石膏〜（001〜009）と目次・巻頭
02_巻中/      黄連〜（010〜032）と目次・巻頭
03_巻下/      香豉〜（033〜052）と目次・巻頭
04_刊記/
  index.md    単位の一覧
  NNN.md      原文（句読点つき）＋校異・校訂
  NNN.ja.md   日本語訳と解説
```

- 単位の番号は、東大本の順に薬に振ったもの。当帰・芎藭は1単位である。
- 東洞先生著述書目記、目次、巻頭、刊記は原文のみで、訳はない。

訳のファイル（`.ja.md`）の頭には `unit` `lang` `source`（対応する原文のファイル）を付けている。

### 原文の句読点

原本の圏点を、規則で句点と読点に分けた。也・矣・焉などの文末の字のあと、文頭の語の前、行の終わりは句点、それ以外は読点とし、全篇を読んで、規則で分けられない箇所を直した。ただし、圏点のあとに文末の字がない文の切れ目には、読点のままのところが残っている。訳は文意に従って切った。

### 訳と解説の書き方

- 訳は直訳を基本とし、節の見出し（考徴・互考・弁誤・品考）は原文と同じにした。
- 「主之」は「がこれを主る」とした。
- 解説は一般的な解釈を独自の言葉でまとめたもので、現代の注釈書からの引用はしていない。
- 引用元を確かめられなかった点、推定で訳した点は、解説にその旨を記した。
- 句読点は、原文、訳とも「、。」を使う。

## 他の古典との関係

薬徴は，傷寒論と金匱要略の条文を集めて、薬の働きを定める書である。『神農本草経』の主治によらず、陰陽五行や気味の説明を退ける点に特徴がある。各章の「他の古典との関係」には、『神農本草経』や『本草綱目』との違いと、東洞が本草書のどの説を退けたかを記した。

## 底本と本文

### 底本

- **どのような本か**：『藥徴』三巻（東京大学理学系研究科附属植物園所蔵、請求記号 Wa:248、DOI [10.20730/300066046](https://doi.org/10.20730/300066046)）。子の猷（南涯）の跋は天明甲辰（1784）で、刊記の発行書肆は出雲寺文次郎らである。刊年の記載はない。
- **どのように入手したか**：国文学研究資料館の国書データベースで公開されている画像（全139コマ）を見て、1コマずつ書き起こした。
- **字の変換**：書き起こしは原本の字で行い、公開版では日本の新字体に直した（方針は `字体と変換の方針.md`）。「人參」の字は、原本の字形によらず「人参」に統一した。

### 訂正と校異

- 東大本のままとし、明らかな誤刻だけを改めた。改めたのは2か所で、【校訂】として記した（香豉の「其非為吐剤也」、大棗の「以上八方」）。
- 校異は130件で、東大本と比べた資料の字句の違いを【校異】として記した。太字の部分が、資料によって異なるところである。
- 字体だけの違い、通用字、資料の変換の誤り、見出しの違いは記していない。資料全体に一律に見られる次の違いも、各単位には記していない。
  - 東大本の「右」（「右一方」など）を、比べた資料は「上」に作る。
  - 東大本の「学者」「病人」を、殆知閣・Wikisource は「学人」「病患」に作る。
- 比べた資料は同じ系統のテキストと見られるので、資料が一致していても、東大本の誤りとは限らない。
- 東洞の引用が引用元と異なるところは改めず、気づいたものを解説に記した。

### 確かめていないこと

- 全単位の原文と訳を読み比べたが、訳は別の注釈書や現代語訳と照合していない。未確認の訳を含む。
- 書き起こしは比べた資料との差を手がかりに確かめたが、全コマを読み直してはいない。資料と同じ字に読み誤っている場合は、見つかっていない。
- 訳の解説の一部（木芍薬の比定、「游断」「俏性」の解釈など）は推定である。
